### feat(orders) — order email notification

New feature: when a Stripe payment transitions to `paid`, the shop now sends an
order notification to `vente@karnain.fr` via SMTP through the brand's own o2switch
mailbox. Key design decisions encoded in the commit:

- Sent via o2switch (domain SPF + DKIM) rather than from Vercel to avoid spam
  classification for `karnain.fr` messages.
- Fires in `after()` so the 200 is already on its way to Stripe before the SMTP handshake.
- Idempotent: `markPaid` scopes its update to `pending` rows only — a redelivered
  Stripe event updates nothing and sends nothing.
- Gated on config (`SMTP_HOST`, `SMTP_USER`, `SMTP_PASSWORD`, `MAIL_FROM`): the app
  builds and runs without SMTP variables exactly as before.
- New module: `src/core/mail/server.ts` (nodemailer, server-only) + `src/features/admin/order-notification.ts`.
